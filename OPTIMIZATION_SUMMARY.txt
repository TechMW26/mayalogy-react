⚙️ TECHNICAL DETAILS
════════════════════════════════════════════════════════════════════════════

Cache Implementation:
- Cache Key: Hash of (systemInstruction + prompt)
- TTL: 1 hour (3600000ms)
- Storage: In-memory Map()
- Expiration: Automatic (checked on access)
- Clearing: On page refresh (intentional for fresh data)

Batch Processing:
- Batch Size: 3 concurrent requests
- Delay Between Batches: 50ms
- Purpose: Prevent rate limiting (429 errors)
- Configurable: Yes (via batchSize parameter)

Request Queue:
- Max Concurrent: 3 requests
- Queue Management: FIFO (First In, First Out)
- Error Handling: Graceful with retries
- Stats Tracking: Hit count, duration, success rate
